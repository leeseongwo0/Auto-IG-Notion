# 인사이트 노트 프로토타입

`index.html`을 브라우저에서 엽니다. HTML 파일 하나에 스타일, 스크립트, 샘플 데이터와 도형이 포함되어 있으며 별도 서버나 패키지 설치, 외부 요청이 필요하지 않습니다.

이 화면은 Notion 성과 공간의 정보 구성과 사용 흐름을 검토하기 위한 웹 목업입니다. 실제 Notion 화면이나 연결된 서비스가 아닙니다. 모든 지표·콘텐츠·실행 기록은 가상의 샘플이며 실제 계정과 비공개 페이지 주소를 포함하지 않습니다.

## 확인할 흐름

- 기간을 바꾸며 계정 요약과 추이를 비교합니다.
- 게시물·릴스를 검색하거나 종류별로 필터링하고 상세 지표를 엽니다.
- 콘텐츠를 캘린더와 목록으로 봅니다.
- 수집 시뮬레이션을 실행하고 상태 변화를 확인합니다. 실제 수집·저장·예약은 발생하지 않습니다.

계정의 기간별 조회·도달, 팔로워 순간값, 콘텐츠 누적값은 서로 다른 범위로 표시합니다. 제공되지 않은 지표는 `—`로 표시합니다.
